# Manual de moderación del foro UFOlogist

## Objetivo

La moderación protege simultáneamente a las personas, la calidad de la evidencia
y la libertad de explorar hipótesis. No decide qué debe creer la comunidad:
mantiene conversaciones verificables, seguras y útiles.

## Prioridades

1. Riesgo físico, amenazas, datos personales y contenido ilegal.
2. Suplantación, fraude, evidencia manipulada o campañas coordinadas.
3. Acoso, discriminación y ataques personales.
4. Spam, autopromoción y duplicados.
5. Calidad editorial: títulos, fuentes, categorías y contexto.

## Flujo de revisión

1. **Conservar evidencia interna.** Guarda enlace, fecha y motivo de actuación.
2. **Reducir daño.** Oculta primero datos personales o instrucciones peligrosas.
3. **Clasificar.** Distingue error honesto, contenido insuficiente y engaño.
4. **Actuar proporcionalmente.** Solicitud de edición, aviso, bloqueo temporal o
   suspensión.
5. **Explicar.** Cita la norma concreta y describe qué permitiría restaurarlo.
6. **Revisar apelaciones.** Siempre que sea posible, un segundo moderador revisa
   decisiones graves.

## Matriz de respuesta

| Situación | Primera respuesta | Reincidencia o gravedad |
|---|---|---|
| Falta de fuente o contexto | Pedir información y marcar `Datos insuficientes` | Cerrar si no se actualiza |
| Título sensacionalista | Editar el título y explicar el criterio | Limitar publicaciones repetidas |
| Duplicado | Enlazar y cerrar a favor del hilo principal | Aviso por spam |
| Autopromoción relevante | Pedir declaración de interés y contexto | Retirar enlaces repetitivos |
| Ataque personal | Ocultar comentario y advertir | Suspensión temporal |
| Doxxing o amenaza | Ocultar inmediatamente | Suspensión y escalado |
| Evidencia manipulada no declarada | Marcar y solicitar original | Suspensión si existe engaño deliberado |
| Contenido generado por IA como recreación | Exigir etiqueta visible | Retirar si se presenta como evidencia |
| Conducta peligrosa o intrusión | Cerrar y mostrar advertencia de seguridad | Suspensión |

## Revisión técnica mínima de un caso

- Comprobar fecha, zona horaria y ubicación aproximada.
- Buscar discontinuidades, recortes o transcodificaciones evidentes.
- Preguntar por archivo original y dispositivo.
- Comparar duración y trayectoria con tráfico aéreo y orbital cuando proceda.
- Revisar meteorología, astronomía, reentradas y eventos locales.
- Separar testimonios independientes de republicaciones de una misma fuente.
- Registrar qué hipótesis se probaron y por qué se mantienen o descartan.

## Estados y cierres

Un caso no se marca `Explicado` solo porque una hipótesis sea posible. Debe
explicar razonablemente tiempo, dirección, movimiento, apariencia y contexto.
`Sin resolver` tampoco significa “extraordinario”: puede indicar que faltan datos.

Los cierres deben incluir:

- conclusión provisional;
- evidencia principal;
- límites conocidos;
- enlaces relevantes;
- condición que justificaría reabrir el análisis.

## Cadencia operativa

- Revisión diaria de reportes y menciones.
- Revisión semanal de hilos sin respuesta o con etiquetas inconsistentes.
- Resumen mensual de casos explicados, abiertos y bloqueados.
- Auditoría trimestral de decisiones controvertidas y normas.

## Métricas saludables

Medir respuestas útiles, fuentes primarias aportadas, casos actualizados,
explicaciones documentadas, tiempo hasta primera respuesta y carga de moderación.
No optimizar por cantidad bruta de publicaciones o reacciones.

## Plantilla de aviso

```text
Moderación UFOlogist

Hemos intervenido este contenido por: [norma concreta].
Acción realizada: [edición / ocultación / cierre / suspensión].
Puedes corregirlo aportando: [fuente, contexto o cambio solicitado].
Si crees que falta información, responde a este aviso para solicitar revisión.
```
